# Metal Alloys - Система прогнозирования свойств сплавов

## О проекте

**Metal Alloys** — это веб-приложение для прогнозирования механических свойств металлических сплавов на основе их химического состава и параметров обработки. Система использует машинное обучение для предсказания характеристик сплавов, а также предоставляет функционал для управления патентами, пользователями и историей прогнозов.

Ключевой особенностью системы является интеграция с LLM (DeepSeek API) для автоматической структуризации и анализа патентных данных.

## Архитектура проекта

Проект состоит из четырех основных частей:

1. **Backend** (`diploma_back`) — REST API на FastAPI.
2. **Frontend** (`diploma_front`) — React-приложение.
3. **ML модули** — скрипты для обучения и инференса моделей.
4. **LLM Analyzer** — модуль для анализа патентов через DeepSeek API.

## Установка и запуск

### Backend

1. Перейдите в директорию backend:
```bash
cd diploma_back
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
   ```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Настройте конфигурацию в application/config.py и добавьте ключ API DeepSeek в переменные окружения (см. раздел "Настройка окружения").

5. Запустите сервер:
```bash
uvicorn main:app --reload --port 8000
```

### Frontend

1. Перейдите в директорию frontend:
```bash
cd diploma_front
```

2. Установите зависимости: 
```bash
npm install
```

3. Запустите приложение:
```bash
npm start
```

### ML  модели

Для обучения моделей:
```bash
cd diploma_ml_scripts
python analyze_categories.py
python aplit.py
python classifier.py
python train_regressors.py
```

### LLM Analyzer

Модуль расположен в отдельной директории diploma_llm_analyzer. Для его работы необходимо настроить API ключ DeepSeek и Яндекс Диска.
```bash
python llm_analyzer.py
```

# Права доступа

## Роли пользователей

| Роль | Описание | Права |
|------|----------|-------|
| `admin` | Администратор | Полный доступ ко всем данным, управление пользователями и ролями |
| `researcher` | Исследователь | Создание прогнозов, управление своими данными, просмотр патентов, запуск LLM-анализа |

### Проверка прав

- **Админ** видит и редактирует все данные.
- **Исследователь** видит только свои прогнозы и патенты, где он автор.
- **Обычный пользователь** видит только свои данные.

- Предсказание свойств сплавов.

# LLM Analyzer Module

Модуль `llm_analyzer.py` отвечает за интеллектуальную обработку патентной документации.

**Основные функции:**
- **Извлечение текста:** Парсинг загруженных PDF или текстовых файлов патентов.
- **Структурирование:** Отправка текста в DeepSeek API с промптом для извлечения структурированных данных (JSON).
- **Сохранение:** Запись полученных данных в базу данных (таблица `patents`).

**Пример использования:**
```python
# Пример кода для анализа патента
result = llm_analyzer.analyze_patent("path/to/patent.pdf")
print(result)
```

Отчеты генерируются в формате PDF с:

- Ключевыми показателями системы.
- Диаграммами распределения прогнозов.
- Статистикой по ML моделям.
- Списком последних прогнозов.
- Активностью пользователей (для админа).

**Пример отчета для админа:**
- Все пользователи системы.

# Разработка

## Добавление новой ML модели

1. Обучите модель в `diploma_ml_scripts/train_regressors.py`.
2. Сохраните модель в `ml_models/`.
3. Добавьте запись в таблицу `ml_models` через API.
4. Обновите `MLInference` класс для поддержки новой модели.

## Добавление нового типа отчета

1. Создайте новый метод в `routes.py`.
2. Добавьте сбор необходимых данных.
3. Используйте `ReportLab` для генерации PDF.
4. Добавьте маршрут в API.

## Расширение LLM-анализатора

1. Обновите промпты в `llm_analyzer.py` для извлечения новых полей.
2. Добавьте новые поля в модель БД `patents`.
3. Обновите схему ответа API.

# Устранение неполадок

## Частые проблемы

### Ошибка подключения к БД
- Проверьте путь к файлу `application.db`.
- Убедитесь, что директория доступна для записи.

### Ошибка генерации PDF
- Убедитесь, что установлены шрифты для кириллицы.
- Проверьте права на запись в `uploads/temp_charts/`.

### Ошибка ML предсказания
- Проверьте наличие обученных моделей в `ml_models/`.
- Убедитесь, что входные данные валидны.

### Ошибка LLM Analyzer
- Проверьте validity API ключа `DEEPSEEK_API_KEY`.
- Убедитесь, что есть доступ к интернету для запросов к API.
- Проверьте лимиты токенов в вашем аккаунте DeepSeek.
